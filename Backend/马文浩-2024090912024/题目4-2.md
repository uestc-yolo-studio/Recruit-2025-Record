# 4.2 SQL基础查询

### 基础咒语联系

```Sql
select * from students where student_name like "张%" or"李%";	//找出所有姓李或姓张的学生
select * from students where gender = 'F' and Year(birth_date) = 2003;	//找出2003出生的女生信息
select * from scores where score between 80 and 90;    //找出成绩在80-90的记录
select student_name, email from students limit 5;	//找出前五条学生的名字和邮箱
select * from students where student_name like '%三%'; //名字中包含三
```

### 复合咒语联系

```sql
select c.class_name, count(s.student_id) as scount from classes c, students s where c.class_id = s.class_id group by c.class_name having scount >2;	//统计每个班级的学生总数，但只显示人数超过2人的班级。

select s.student_name ,avg(score) as avgs from students s, scores sc where s.student_id = sc.student_id group by s.student_id order by avgs desc limit 3;	//计算每位学生的平均分，并按降序排列，列出前三名学霸。

select t.teacher_name,c.course_name,count(distinct sc.student_id) from teachers as t,courses as c where t.teacher_id = c.teacher_id and t.title = '教授' group by t.teacher_name,c.course_name;  //查询教授所讲授的所有课程，以及选修这些课程的学生数量。

select c.course_name ,avg(score),max(score),min(score) from courses c,scores s where c.course_id = s.course_id group by c.course_name ;	//计算每门课程的平均分、最高分和最低分。

select s.* from students s,courses c,scores sc where (c.course_name ='数据库原理' or '数据结构') and sc.course_id =c.course_id and sc.score >= 85 and s.student_id = sc.student_id  
//找出所有选修了“数据库原理”或“数据结构”，并且成绩不低于85分的优秀学生信息。
```
