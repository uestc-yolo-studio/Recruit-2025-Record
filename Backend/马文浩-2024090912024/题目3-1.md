# 3.1 创生之初：定义“宠物”这一概念 (类与对象)

## 3.1.1 对于类的理解

类，是对象的**完整蓝图**，定义了对象的**状态**（字段）和**行为**（方法），并提供了创建对象的构造方法，它的核心是**“是什么”**和**”怎么做“**。但没有实现**”做什么“** 和**”具体是什么“**的能力。

## 3.1.2 对于对象的理解

对象，是类的实例化，是根据“蓝图”所描绘的实际对象，可以做到类所规范的**“可以做的事”**以及拥有**”实际的属性“**。

## 3.1.3 如何刻画“内在属性”和“外在行为”

宽泛的讲，使用**成员变量**刻画内在属性，使用**成员方法**刻画外在行为。

### 3.1.4 我的动物朋友实例

**类的建立**

```java
public class MagicPanda {
    // 内在属性：名字、年龄、饥饿值
    String name;
    int age;
    int hungerValue;
    int petLoyalty;

    // 构造器
    public MagicPanda(String petName, int petAge, int petHungerValue) {
        name = petName;
        age = petAge;
        hungerValue = petHungerValue;
        petLoyalty = 50;
    }

    // 外在行为：吃饭（吃饭后饥饿值降低，忠诚度增加）
    public void eat() {
        System.out.println(name + "正在吃饭~");
        hungerValue -= 20;
        petLoyalty += 10;
        System.out.println(name + "吃饭后，饥饿值变为：" + hungerValue);
        System.out.println(name + "玩耍后，忠诚度变为：" + petLoyalty);
    }

    // 外在行为：玩耍（玩耍后饥饿值升高,忠诚度增加）
    public void playWithMe() {
        System.out.println(name + "正在玩耍~");
        hungerValue += 10;
        petLoyalty += 10;
        System.out.println(name + "玩耍后，饥饿值变为：" + hungerValue);
        System.out.println(name + "玩耍后，忠诚度变为：" + petLoyalty);
    }
}
```

实例化对象以及**测试程序**

```java
public class MagicPandaTest {
    public static void main(String[] args) {
        MagicPanda myPanda = new MagicPanda("花花", 2, 50);
        myPanda.eat();
        myPanda.playWithMe();
    }
}
```
