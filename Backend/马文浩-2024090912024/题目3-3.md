# 3.3 高级构造技巧：内部类与设计模式

## 3.3.1内部类

### 成员内部类

- **定义**：定义在另一个类（外部类）内部的普通成员类，就叫成员内部类。
- **特点**：可以访问外部类的所有成员；依赖于外部类的对象存在，即必须先创建外部类对象，才能创建成员内部类对象；在成员内部类中，不能有静态成员（除非是 `static final` 修饰的常量），其他都有。
- **适用场景**：当一个类中需要使用另外一个类，而这另外一个类没有必要单独定义，就在类中定义成员内部类。

### 静态内部类

- **定义**：用 `static` 修饰的内部类，属于外部类本身，而不是外部类的实例。
- **特点**：不依赖于外部类的对象，可以直接通过外部类名访问；只能访问外部类的静态成员，不能访问外部类的实例成员；可以有自己的静态成员和实例成员。
- **适用场景**：当内部类不需要访问外部类的实例成员，且希望内部类能独立于外部类对象存在时使用。

### 局部内部类

- **定义**：定义在方法、代码块等局部区域内的类。
- **特点**：作用范围仅限于定义它的局部区域；可以访问外部类的所有成员，也可以访问所在方法中被 `final`修饰的局部变量；不能有访问修饰符，也不能用 `static` 修饰。
- **适用场景**：主要用于在某个方法内部需要一个临时的类来辅助完成特定功能，且这个类只在该方法内使用。

### 匿名内部类

- **定义**：没有类名的内部类，通常用于创建一个实现了某个接口或继承了某个类的临时对象。
- **特点**：是一种特殊的局部内部类，定义的同时就创建了对象；必须继承一个类或实现一个接口；不能有构造方法（因为没有类名）；适合创建只使用一次的类对象。
- **适用场景**：当需要快速创建一个实现了某个接口或继承了某个类的对象，且该对象只使用一次时使用。

### 链式调用方法的优点

- **应对参数过多**：传统构造方法因参数多，参数列表冗长、可读性差。而建造者模式通过分步设置参数，让代码更清晰，比如设置`name`、`age`后，再按需设置`favoriteFood`、`canFly`，阅读及使用成本降低。
- **处理可选参数**：建造者模式里可选参数有默认值，使用时，只需对有特殊需求的可选参数进行设置，无需在构造时传递所有可选参数，复杂度小。
- **不可变对象**：`PetProfile`的属性都是`final`的，对象创建后属性不可变。建造者模式在构建完成后才生成`PetProfile`对象，保证了对象的不可变性，有助于避免对象状态被意外修改。

### Comparator应用

```java
        Array.sort(petArr, new Comparator<Pet>() {
            @Override
            public int compare(Pet pet1, Pet pet2) {
                return pet1.getAge() - pet2.getAge();
            }
        });//匿名内部类
```

```java
	 Array.sort(petArr, (pet1, pet2) -> pet1.getAge() - pet2.getAge());//Lambda表达式
```

```java
	public static int compareByAge(Pet pet1, Pet pet2) {
        return pet1.getAge() - pet2.getAge();
    }//类中已定义
	Array.sort(petArr, Pet::compareByAge);//方法引用
```
