# 2.2 第二关：定义生命的流动与呼吸——栈与队列的魔法

## 2.2.1 MyStack

```java
public class MyStack {
	private LinkedList<Integer> list = new LinkedList<>();
    //压栈
    public void push(int value) {
        list.addLast(value);
    }
    //出栈
    public int pop() {
        if (isEmpty()) {
            System.out.println("栈为空，无法弹出元素")；
        }
        return list.removeLast();
    }
	//获得栈顶元素
    public int peek() {
        if (isEmpty()) {
            System.out.println("栈为空，无法查看元素");
        }
        return list.getLast();
    }

    // 判断栈是否为空
    public boolean isEmpty() {
        return list.isEmpty();
    }
}
```

## 2.2.2 MyQueue

```java
public class MyQueue {
    private LinkedList<Integer> list = new LinkedList<>();

    // 入队
    public void enqueue(int value) {
        // 添加到链表尾部，模拟入队
        list.addLast(value);
    }
    // 出队
    public int dequeue() {
        if (isEmpty()) {
            System.out.println("队列为空，无法出队");
        }
        return list.removeFirst();
    }

    // 查看队头元素
    public int peek() {
        if (isEmpty()) {
            System.out.println("队列为空，无法查看元素");
        }
        return list.getFirst();
    }

    // 判断队列是否为空
    public boolean isEmpty() {
        return list.isEmpty();
    }
}
```
