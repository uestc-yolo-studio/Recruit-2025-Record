# 5.3 设置自动化魔法符文 (触发器)

```sql
//当一只宠物从档案中被删除时，自动清除所有与它相关的领养契约记录。
DELIMITER $$
CREATE TRIGGER del_pet
BEFORE DELETE ON Pet
FOR EACH ROW
BEGIN
    DELETE FROM Adoption_Record WHERE pet_id = OLD.id;
END$$
DELIMITER ;
//当一位领养人注销档案时，自动清除所有他/她签订的领养契约记录。
DELIMITER $$
CREATE TRIGGER del_adopter
BEFORE DELETE ON Adopter
FOR EACH ROW
BEGIN
    DELETE FROM Adoption_Record WHERE adopter_id = OLD.id;
END$$
DELIMITER ;
```
