**1.**链表的本质可以概括为：**一种通过引用将离散的内存单元（节点）串联而成的线性数据结构**

| 特性维度             | **数组 - 静态的晶体阵列**                                 | **链表 - 动态的生命链条**                               |
| :------------------- | :-------------------------------------------------------- | :------------------------------------------------------ |
| **内存结构**         | **连续内存块 **内存地址相邻                               | **非连续节点** 内存空间不连续，靠地址引用连接           |
| **大小特性**         | **固定尺寸** 创建时就必须确定大小，难以改变               | **动态伸缩** 可随时生长或收缩，按需分配                 |
| **增删效率**         | **O(n)** 插入/删除需移动后续所有元素                      | **O(1)**（已知位置时） 仅需修改引用，如同改变指针方向   |
| **访问（查找）方式** | **随机访问 - O(1)** 通过索引直接寻址                      | **顺序访问 - O(n)** 必须从头遍历，像顺着线索一步步寻找  |
| **内存效率**         | **可能浪费或不足** 预分配过多则浪费，不足则需重建整个阵列 | **按需使用** 无内部碎片，但每个节点有额外引用对象的开销 |
